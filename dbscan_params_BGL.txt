🔍 Flow Pencarian Parameter Optimal
PART 2: K-Distance Analysis (Estimasi eps)
Flow:

Sample data: 500K samples (GPU) atau 150K (CPU)
Hitung k-nearest neighbors (k=30) untuk setiap sample
Ambil jarak ke k-th neighbor → k-distance
Sort k-distance dan plot grafik
Hitung percentiles: 50th, 60th, 70th, 80th, 85th, 90th, 95th
Kriteria penentuan eps range:
eps_min = np.percentile(k_dist_clean, 75)    # 75th percentile
eps_max = np.percentile(k_dist_clean, 99)    # 99th percentile

Alasan:

✅ 75th percentile (minimum): Hindari over-merging, jarak terlalu kecil = terlalu banyak noise
✅ 99th percentile (maximum): Hindari under-clustering, jarak terlalu besar = semua jadi 1 cluster
✅ Plot untuk visual inspection: cari "elbow point" (titik lengkungan tajam)

Flow:

Sample 50K data untuk speed (GPU) atau 15K (CPU)

Parameter Grid:
eps_values = 8 nilai dari [eps_min, eps_max]

Kriteria Evaluasi (3 metrics):

Silhouette Score (PRIMARY)

Range: -1 to +1
Kriteria: MAX (semakin tinggi semakin baik)
Interpretasi:
> 0.7 = Excellent separation
0.5 - 0.7 = Good
< 0.5 = Poor/overlapping clusters
Mengukur: Seberapa baik samples terpisah antar cluster
Noise Percentage (SECONDARY)

Kriteria: LOW (< 30% ideal, < 5% excellent)
Interpretasi:
< 1% = Almost all data clustered (sangat baik)
1-10% = Good
> 30% = Too many outliers (eps terlalu kecil)
Mengukur: Berapa banyak data dianggap noise/outlier
Number of Clusters (SANITY CHECK)

Kriteria: REASONABLE (tidak terlalu sedikit/banyak)
Interpretasi:
< 10 = Under-clustering (eps terlalu besar)
10-500 = Good range untuk log data
> 1000 = Over-fragmentation (eps terlalu kecil)
Mengukur: Granularity clustering
Decision Logic:
# Sort by silhouette (descending)
df_res.sort_values('silhouette', ascending=False)

# Top 10 shown, config #1 = best
best_config = df_res.iloc[0]  # Highest silhouette

Mengapa silhouette jadi primary?

✅ Mengukur quality clustering (separation + compactness)
✅ Works tanpa ground truth labels
✅ Balance antara "too few" vs "too many" clusters
